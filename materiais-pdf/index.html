Como os PDFs são feitos

texto primeiro
O conteúdo é escrito e revisado antes da montagem visual. Não uso frases prontas para preencher espaço.
referências visíveis
Quando o tema depende de fonte científica, BNCC ou documento institucional, a referência fica identificada.
visual para ajudar
As imagens servem para organizar o raciocínio. Não substituem a explicação nem viram ilustração decorativa sem função.
uso didático
Os materiais são pensados para estudo individual e para professores que precisam de apoio claro em sala.
