# Portfólio de Copywriting — Marcela Ogioni do Nascimento

Site público: https://marcelaogioniifes-ops.github.io/copywriting/

Portfólio autoral demonstrativo com amostras de comunicação em saúde, ciência para público geral e educação. Inclui carrossel, roteiro de Reels, anúncio, exemplos de conteúdo, processo editorial e referências bibliográficas verificáveis.

As peças são demonstrativas e não representam clientes, campanhas publicadas ou resultados comerciais.
