Antes da abertura integral

Revisão editorial

Estamos conferindo redação, ano/prova, gabarito e fonte institucional de cada item. Quando houver adaptação, ela será marcada explicitamente. Isso evita apresentar uma questão reescrita como se fosse reprodução literal de prova oficial.

Para estudantes

Como usar

Use o banco como treino de interpretação, identificação de conteúdos recorrentes e revisão de conceitos. Para estudo para processo seletivo, compare sempre com os editais e provas oficiais mais recentes.

Para professores

Como citar

Ao reutilizar uma questão oficial, cite a prova/instituição original. Se utilizar classificação, organização ou comentário pedagógico do BioRascunho, mantenha o crédito da curadoria.
